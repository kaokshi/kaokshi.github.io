# Три истории мира — редакция для Дзена

Сайт трёх направлений: «Кадр за Кадром», «Легенды тёмных улиц», «За гранью очевидного».

Техническая основа: GitHub Pages, Python-генератор и три RSS 2.0 ленты.

**Важное:** статьи появляются публично только после редакционного утверждения и проверки лицензий изображений. RSS сам по себе не означает подключения к платформе Дзен.

Подробнее: [инструкция](docs/README_RU.md).

Редакционный контур и офлайн-проверки описаны в [документации ZEN CORE и ZEN CONTROL](docs/EDITORIAL_PRODUCTION.md).
