## Без оплаты и без ручного доступа к сайтам
- ModernBERT: `toiletsandpaper/russian-ai-text-detector-modernbert`, Apache-2.0.
- LightGBM: `toiletsandpaper/russian-ai-text-detector-lightgbm`, MIT.
- AI Accent Detector: `Rain-ouroboros/ai-accent-detector`, MIT, диагностирует **стилистический сигнал**, а не вероятность авторства.
- ModernBERT и LightGBM обучены на одном корпусе LLMTrace — их оценки НЕ две независимые проверки авторства. Реальные оценки моделей и эвристик бывают ошибочными.

## Конструкция
- `requirements-editorial.txt`: отдельные зависимости; существующие зависимости сайта не изменять.
- `src/editorial_ai_check.py`: безопасный сканер статей `content/articles/*.json`. Читает `body_html`, получает обычный текст, вызывает `aiw-ru classify --model modernbert --json` и `--model lightgbm`, затем `ai-accent-detector --json --lang ru`. Вывод — отдельные JSON-файлы.
- `.github/workflows/editorial-ai-checks.yml`: отдельная ручная задача `Editorial AI checks (read-only)`. Не имеет разрешения записывать содержимое репозитория и не запускает генератор сайта.
- `tests/test_editorial_ai_check.py`: быстрые тесты без скачивания моделей.

## Тестовый запуск через GitHub
1. Открыть https://github.com/kaokshi/kaokshi.github.io/actions/workflows/editorial-ai-checks.yml .
2. Выбрать **Run workflow** и при необходимости указать точный slug статьи. Пустой slug проверяет весь набор черновиков.
3. После завершения скачать артефакт `editorial-ai-review` (срок хранения 7 дней), который содержит `index.json` и по одному JSON на статью.
4. При сбое одной из моделей отчёт сохранит ошибку, задача завершится неуспешно, а публикация останется заблокированной.
5. После подтверждения скорости, лицензий, результатов и лимитов можно обсудить периодические запуски и связь с 08:00 МСК.

При испытании ограничьте первый запуск **одной статьёй**: модели скачиваются во время сборки, Actions runner может расходовать время на установку библиотек. Если модель не скачалась, не отмечайте проверку как пройденную.

## Текущая схема: ruBERT v4 главный (решение владельца от 2026-11-19)

- Основной детектор — `k1y0miiii/ru-ai-text-detector`, модель `v4`, обученная на русском, версия кода `244e955427548f5856bb389cc8611f959911290c`, веса Hugging Face `k1y0mi/ru-ai-text-detector` ревизии `175e75ec79e9471f3f5b4ab0da9b859188446807`. Код MIT, для установки используется отдельное окружение `.rubert-venv` и каталог исходников `.rubert-upstream`, создаваемые только в ходе Actions.
- **Единственный внутренний порог:** `rubert_v4.data.probability <= 0.10` (10% включительно). Если результат не получен, нечисловой или выше, `editorial_threshold.passed=false`.
- **ModernBERT, LightGBM, AI Accent Detector** теперь только дополнительные диагностические значения. **Для них нет порога**, они не способны отменить успешную или неуспешную проверку ruBERT. Результаты всегда сообщать точно, не усреднять.
- Важно: собственный обученный порог v4 для вывода класса ИИ около 0.834 для обычных текстов; наш 0.10 — отдельный, заметно более строгий выбор владельца, который может отвергать и человеческие статьи. Калибровку именно наших материалов нужно проверить на корпусе с известным авторством; 10% не показатель качества и не доказательство происхождения.
- Технический workflow только читает материалы и пишет диагностический JSON в артефакт. Он не меняет `approved`, `publication_enabled` или выпуск RSS.
- **Реальный первый прогон подтверждён:** GitHub Actions run [44614176255](https://github.com/kaokshi/kaokshi.github.io/actions/runs/44614176255), фильм «Шоу Трумана», `rubert_v4.probability=0.11267605423927307`, то есть **11,2676%**. Собственный вердикт модели при родном пороге 83,4% — `human`; наша редакционная граница 10% **не пройдена**, поэтому job закономерно завершился ошибкой после полноценной работы 4/4 инструментов. Это не сбой установки. Три другие оценки служат только для сравнения: ModernBERT 0,45%, LightGBM 69,32%, AI Accent 9,91%. Источником этих чисел служит лог `REPORT_JSON_START` и артефакт запуска.

## Защита
- Этот pipeline **никогда** не меняет `config/site.json`, `status`, `ai_reviewed`, `ai_checks`, `editorial_reviewed`, `publication_authorized`, `release_hold` или `publish_at`.
- Никакой автоматической публикации в RSS или Дзене, никаких средств оплаты.
- Новый отчёт носит информационный характер. Публикационный шлюз в `src/build.py` по-прежнему требует ручного подтверждения и двух отдельно зафиксированных завершённых проверок. Не подменять его сырыми результатами этих моделей без согласования редакционной политики.
- Публичный GitHub-репозиторий уже содержит тексты черновиков; артефакты GitHub Actions тоже нельзя считать полностью приватным хранилищем. Для непубличных статей понадобится приватный контур.
- Лицензии, источники и версии зависимостей необходимо регулярно проверять.
