# Источники кадров кино

Каскад проверяет приватный каталог, затем пополняет его через API Wikimedia Commons и, при нехватке подходящих записей, через Internet Archive. Для ручных студийных записей по-прежнему поддерживаются проверенные прямые файлы, если владелец источника разрешил такой способ доступа. Текстовые каталоги и превью не считаются кадрами. Синтетические кадры не используются.

| Источник | Решение |
| --- | --- |
| OutNow | Приоритетный справочник для `Dune: Part Two` (2024). Галерея разделяет 37 кадров сцен, 7 кадров со съёмок и 5 графических материалов. Публичный MCP показывает справочные сведения. Систематический и коммерческий доступ согласуется отдельно, а условия требуют согласия и оплаты для повторного использования. Кадры из галереи не импортируются. [Галерея](https://outnow.ch/en/Movies/2024/Dune-PartTwo/Images/) · [Feeds & MCP](https://outnow.ch/en/Feeds/) · [Условия](https://outnow.ch/en/TOS/) |
| Wikimedia Commons | Подключён через MediaWiki API. Видео сверяется со свойством P10 конкретного фильма Wikidata, годом, типом и источниковой записью. Допускается общественное достояние или CC0 по метаданным Commons. |
| Internet Archive | Резерв через документированный Metadata API. Требуется точная связь P724, метка общественного достояния или CC0 и открытый видеофайл. [API](https://archive.org/developers/md-read.html) |
| TMDB | Имеет официальный платный коммерческий и бесплатный некоммерческий доступ. `/movie/.../images` возвращает фоны, постеры и логотипы, поэтому само наличие файла не подтверждает сцену. Подключение для коммерческой редакции без согласования исключено. [FAQ](https://developer.themoviedb.org/docs/faq) · [Images](https://developer.themoviedb.org/reference/movie-images) |
| Movie Screencaps | Указано некоммерческое и образовательное использование. Для производственного каскада исключён. [Условия сайта](https://movie-screencaps.com/) |
| FilmGrab | Образовательный справочник, доступа для редакционного импортёра не предоставлено. [О проекте](https://film-grab.com/about/) |
| MovieStillsDB | Публичный запрос отклонён HTTP 403. Подтверждённый канал автоматизированного доступа не найден. [Сайт](https://www.moviestillsdb.com/) |
| Screenmusings | FAQ описывает справочную подборку и fair use. Публичная документация о разрешённом импорте не найдена. [FAQ](https://screenmusings.org/faq/) |
| Cap-That | Архивы выдаются по запросу, владелец запрещает прямые ссылки на файлы. Публично разрешённого API импорта не найдено. [FAQ](https://www.cap-that.com/site/) |
| Shot.Cafe | Условия прямо запрещают доступ ботами и скриптами. [Условия](https://shot.cafe/terms) |
| Официальные пресс-киты | Sony и Paramount ограничивают автоматический сбор. Netflix выдаёт ресурсы через профессиональный пресс-аккаунт. Подключаются только прямые источники с разрешённым способом передачи. [Sony](https://www.sonypictures.com/corp/tos.html) · [Paramount](https://www.paramount.com/paramount-press-express-terms-of-use) · [Netflix](https://media.netflix.com/en/apply) |

Кэш хранит JPEG, SHA-256, pHash, отметку времени, URL и QID в приватном репозитории. При чтении исполнитель заново сверяет хеш и точный путь. Для архивного фильма название, год, режиссёр и актёры сверяются с Wikidata, независимо от наличия статьи в русской Википедии. Сюжетные пересказы требуют отдельной глубины доказательств. Отбор под раздел повторно проверяется SigLIP, CLIP и Qwen. Обложка проходит проверку всей серии изображений. Полнота сборки и состояние публикации проверяются отдельно.
