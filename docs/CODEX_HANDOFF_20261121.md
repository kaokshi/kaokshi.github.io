- Перед кодом зафиксируй `git status`, HEAD, base branch, реальные настройки флагов и список задач.
- Делай небольшие логичные коммиты, отдельный PR поверх актуальной ветки или работай в рамках явно предоставленного рабочего PR по безопасной процедуре, без прямого merge.
