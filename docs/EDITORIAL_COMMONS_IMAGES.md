# Поиск иллюстраций через Wikimedia Commons (только кандидаты)

Модуль `src/editorial_commons_images.py` ищет изображения по тематическим запросам в открытом API Wikimedia Commons **без фильтра по лицензии**. В выборку входят и записи с неизвестными или ограничивающими условиями использования; это поиск кандидатов, а не разрешение публиковать их. Для каждого кандидата сохраняются название, оригинальная страница, адрес изображения, заявленная лицензия, автор, требования к атрибуции и размеры. Эта информация нужна для дальнейшей ручной или отдельной проверяемой автоматической проверки.

**Важно:** машинно указанная лицензия не доказывает права на использование. Программа всегда сохраняет `license_verified=false`, `semantic_match_verified=false` и `editor_approved=false`. Ни один кандидат не добавляется в статьи и RSS автоматически. Для научпопа особенно важно, что изображение может быть визуально похожим, но научно неверным (например, фотография обычной молнии вместо красного спрайта). Для мистики можно использовать подходящие реальные кадры, но они не должны выдаваться за события истории.

## Пример запуска (исполняется вне публичного хранилища)

```bash
python src/editorial_commons_images.py \
  --query "red sprites thunderstorm" \
  --query "mesosphere storm clouds aerial" \
  --output "$HOME/.local/share/zen-editorial-private/science-sprites-image-candidates.json"
```

Следующий этап: расширить поиск за пределы Wikimedia Commons (например, подходящие кадры из фильмов, фотографии из открытых каталогов и редакционных источников), а затем выбрать 7–8 уместных оригинальных изображений без повторов, вручную или через доверенный процесс удостовериться в согласии лицензии, необходимости указания автора, личности людей, брендов и ограничениях изображения, проверить качество, записать файл и подтверждённые права. Только после этого материалы можно включать в черновик для согласования владельцем. Указать в итоговом отчёте все не закрытые проверки и не трактовать число найденных кандидатов как число иллюстраций, пригодных для публикации.

Любые проблемы сети и неполные метаданные не должны переходить в фиктивные "rights verified". Отчёт с результатами поиска остаётся приватным, только метаданные; сами картинки не скачиваются.

Следует помнить: ZIP-пакеты на согласование формируются отдельно `src/editorial_owner_packet.py`. Ни один модуль не отправляет статьи или картинки в Дзен.
