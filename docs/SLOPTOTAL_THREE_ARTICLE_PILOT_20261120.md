# SlopTotal: локальная автоматическая проверка трёх статей, 20.11.2026

**Эксперимент, не автоматизация публикации.** При создании PR автоматически срабатывает `SlopTotal 3-article pilot (self-hosted, free, read-only)`.

Используем оригинальный открытый проект https://github.com/pablocaeg/sloptotal. Согласно документации, Docker self-hosted сервер поднимает API `POST /api/analyze`, возвращающий `overall_score` (0–100) и `overall_verdict`; запускается на CPU, поддерживает русский, но точность на нашем материале ещё требуется проверить.

Система автоматически:
1. Проверяет код без внешних вызовов.
2. Загружает self-hosted SlopTotal Docker image на стандартный GitHub-hosted runner (профиль lite, CPU), локально на 127.0.0.1:8000; ждёт `/api/engines`.
3. Читает **весь исходный body_html** каждого из трёх файлов `legends-01-prohodnaya-17`, `science-08-sinie-ogni-idzena`, `cinema-01-truman-show-real-photos`, удаляет HTML и отправляет русский текст только в локальный `/api/analyze`.
4. Сохраняет JSON, SHA-256 текста и результаты; при сбое не выдумывает процент.
5. Предоставляет артефакт `sloptotal-three-article-diagnostics` в GitHub Actions на 7 дней.

Объём скачиваемых моделей может достигать ~9 ГБ; типичный общий footprint ~8.3 ГБ RAM. На GitHub-hosted Ubuntu с ограниченным диском Docker image плюс cache могут не поместиться. Если нет — не считать запуск успешным и искать более лёгкий локальный вариант. Первую проверку проводить без подмены оценок.

Сведения о сравнении: ZeroGPT **по наблюдениям владельца на полных DOCX**: legends 0%, science 5%, cinema 0%. Sapling ранее проверял 1900 символов и получил 86.6%, 100%, 99.9%. SlopTotal тестирует очищенные **полные исходные тексты**; из-за возможного отличия HTML/подписей эти замеры нельзя назвать проверками строго одного хеша. Результаты у разных детекторов не трактовать как один и тот же процент авторства.

Действующее `publication_enabled=false`, канал cinema на паузе, RSS не меняем. Не добавлять detector как автоматический gate до независимой оценки качества. Лицензии каждого загружаемого модельного веса и реальные нагрузки проверить перед продакшеном.
