# Важное: публикации отключены

Сайт работает в режиме **ожидания**. В `config/site.json` установлен параметр `"publication_enabled": false`.

Пока он не изменён на `true`, генератор **не выводит статьи ни на сайт, ни в RSS** — даже если в отдельном материале выставлены `approved`, подтверждены проверки или настала дата публикации.

Изменение этого параметра допускается **только после отдельного согласования с владельцем проекта**. Подключение RSS в кабинете Дзена — отдельное действие; этот репозиторий не может автоматически отправить заявку в Дзен.

**Осторожно:** файлы черновиков в `content/articles/` находятся в публичном репозитории GitHub и доступны по прямым ссылкам на исходники, хотя не опубликованы на самом сайте. Если тексты должны оставаться полностью закрытыми до публикации, их следует хранить в приватном репозитории (и отдельно организовать сборку публичного сайта), а открытые копии удалить с очисткой истории Git.

Проверка: `python -m unittest discover -s tests -v`.
