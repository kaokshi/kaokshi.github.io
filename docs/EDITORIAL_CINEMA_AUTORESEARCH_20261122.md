# Автономный поиск источников: «Кадр за Кадром» (22.11.2026)

Статус: черновая реализация, **не разрешение на публикацию**.

## Реализованный маршрут

1. Существующий планировщик Qwen самостоятельно выбирает три фильма в дневном плане девяти статей. Желательный формат темы: «Название» (год) — обзор. Anti-duplicate остаётся включённым.
2. Для cinema очередь автоматически вызывает киноисследование, если приватные документы не были предоставлены ранее.
3. Новый movie_autonomous_research.py использует официальные Wikidata API wbsearchentities/wbgetentities. Он требует ровно один подходящий фильм, точное название, класс film/feature film и совпадение года, если он указан.
4. Через ru.wikipedia.org/w/api.php читается реальный раздел «Сюжет» или «Содержание». Отсутствие достаточного текста или неоднозначный фильм даёт fact_check_pending до запуска автора. Источник и паспорт фильма сохраняются приватно, передаются писателю как документы, а не как выдуманные знания модели.
5. Имеющийся редакционный поиск Wikimedia Commons подбирает по фильму и году только кандидатов на изображения. Список и заявленные условия лицензий записываются в movie-image-candidates.json; никакого скачивания фильма или автоматического использования найденных фото нет.

## Ограничения

Это идентификация фильма и получение вторичных материалов, **не** подтверждение каждой сюжетной сцены. Система явно сохраняет plot_events_verified_against_film=false, character_roles_verified=false, publication_authorized=false. Актёр не тождественен персонажу. Сведения Wikipedia/Wikidata тоже могут ошибаться, поэтому требуется следующий этап claim-by-claim проверки по независимым источникам.

Кандидаты Commons пока не проверены на совпадение с конкретной сценой и законность дальнейшего применения. Нет автоматического скачивания защищённого видео, обхода DRM и выдуманных кадров. TMDB пока не подключён: необходимы API-учётные данные и подходящие условия для коммерческого использования.

Ошибки сети и неоднозначности не выдаются за успешные проверки. Публикация GitHub Pages и RSS остаётся отключённой, приватные тексты не загружаются в публичный репозиторий.

## Как проверить

Offline: python -m unittest tests.test_movie_autonomous_research -v

Тест включён в существующий model-a-agent-v1-tests.yml, проверяет выбор фильма, отклонение неправильного года, неоднозначность, отсутствие сюжета, отказ от вымышленных источников и интеграцию с очередью. Требуется подтвердить GitHub Actions CI и провести реальный безопасный сетевой пилот без публикации.

Следующие этапы: более точная проверка персонажей/ролей и отдельных утверждений, затем визуальная проверка тематических кандидатов и безопасное извлечение кадров только из разрешённых видеоматериалов.
