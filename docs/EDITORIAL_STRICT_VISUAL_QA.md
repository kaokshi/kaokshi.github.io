# Усиленная семантическая проверка редакционных изображений (эксперимент)

Статус: **исследовательский контур; не внедрён в действующую редакцию и не имеет разрешения публикации**.

## Реализовано
- `src/editorial_visual_constraints.py`: структурные ограничения `must_include`, `must_avoid`, `count_requirements` с `mode=exact`. Явный запрет считать подпись Florence-2 или относительный score SigLIP2 независимым доказательством объектов и чисел.
- `src/editorial_images.py::generated`: при `EDITORIAL_IMAGE_FEEDBACK_EXPERIMENT=true` выполняет до трёх новых генераций Klein; каждый вариант проходит SigLIP/Florence; обязательные детали должны иметь независимое подтверждение, иначе кандидат **не сохраняется как принятый**; при исчерпании попыток возвращается `generated_image_required_details_not_verified`.
- `best_candidate`: тестируемый детерминированный выбор подтверждённой лучшей попытки вместо последней. **В основном цикле генерации сохраняется первый полностью подтверждённый вариант**, экономя вызовы; это не exhaustive best-of-three. Для неподтверждённых кандидатов нет автоматического допуска.
- Legacy/default путь остаётся неизменным. Режим с проверкой **не включён** по умолчанию.
- Отсутствуют фиктивные согласования и автоматическая публикация; права, наука и оригинальность всё равно требуют отдельной проверки.

## Условия допуска к центральному агенту PR №66
1. Объектный детектор должен корректно распознать и посчитать критичные элементы на независимых изображениях с реальными сложными негативами. Только 3 картинки часов **недостаточны** для оценки процента ошибок.
2. Полный Klein → все проверки → повторная генерация должен пройти на реальных задачах, а не только на mock-тестах.
3. Система должна сохранять реальные исходные и промежуточные изображения и точные причины отклонений, не превышать бесплатную квоту.
4. Если обязательное количество объектов нельзя проверить достоверно, отправить на согласование владельцу, а не выдавать `approved`.
5. Проверки прав изображений, фотоподлинности научпопа, отсутствия фальшивых кинокадров и заморозка публикации сохраняются.

**До выполнения условий не включать экспериментальные модели в основной workflow.** При их провале использовать проверенный существующий режим и показывать владельцу проблемные кадры.
