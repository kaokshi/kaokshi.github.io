# Экспериментальный визуальный контролёр — Qwen на Cloudflare

Дата: 21.11.2026.

## Принятое решение

Выбран `@cf/qwen/qwen3.8-27b` на существующем Cloudflare Workers AI как **экспериментальный** независимый от FLUX генератора семантический проверяющий. Сервис облачный, не требует пользовательского компьютера, использует тот же пул бесплатной квоты Neurons, что FLUX. Альтернативная Florence-2 не подключается: полезна для выявления объектов, но не заменяет сквозной анализ сюжета и пространства.

Официальная модель: https://developers.cloudflare.com/workers-ai/models/qwen3.8-27b/ .

## Реализация

- `src/editorial_cloudflare_vision.py`: отправляет две реальные картинки (исходную и после Klein) с паспортом сцены, получает JSON с шестью флагами и конкретными дефектами, записывает SHA-256 обоих изображений.
- `tests/test_editorial_cloudflare_vision.py`: проверки схемы, правильного пиксельного ввода, отказа при отключенном пилоте, запрета автоматически считать модель подтверждением.
- `.github/workflows/cloudflare-vision-pilot.yml`: отдельный пилотный запуск на картинках из старых приватных GitHub Actions artifacts.
- `ZEN_IMAGE_VISION_PILOT=true` требуется только для ручного/изолированного теста, в основном конвейере флаг не установлен.
- `ZEN_IMAGE_ALLOW_PAID=false`, `ZEN_CLOUDFLARE_FREE_PLAN_CONFIRMED=true`, нет платного fallback или Modal.

## Реальные испытания

- Первое испытание https://github.com/kaokshi/kaokshi.github.io/actions/runs/44906297643 : модель вернула ответ в неподходящем для JSON парсера формате; статус `pilot_failed`; негативной семантической валидации не было.
- После уточнения параметров генерации https://github.com/kaokshi/kaokshi.github.io/actions/runs/44906426638 : парсер обработал JSON и модель отметила все шесть пунктов положительно, но её вердикт остаётся `needs_independent_validation`, `semantic_verified=false`.
- Проводится отрицательный контроль с несовпадающими сценами — https://github.com/kaokshi/kaokshi.github.io/actions/workflows/cloudflare-vision-pilot.yml .

## Условия перехода к автономности

1. Не меньше 20–30 независимо размеченных сложных и простых примеров, включая корректные кадры, явные несоответствия и изменения смысла после Klein.
2. Критические ложноположительные результаты («всё правильно» при неправильно изображённой сцене) недопустимы без отдельного порога и защиты.
3. Для science рисунки и метки дополнительно сверяются с авторитетными научными первоисточниками; VLM не является фактчекером сам по себе.
4. Утверждение кандидата исключительно при подтверждении надежности модели и отдельной проверке всех важных полей; до этого `media_production_pending`, оригинал и Klein версия сохранены отдельно.
5. Отслеживать реальный расход Neurons из Cloudflare dashboard. Нельзя обещать точный бесплатный бюджет без реальных данных.

Публикация выключена. Научпоп сохраняет смешанную политику: настоящие фото — первичный источник, схемы и 3D для объяснения, анимация только по необходимости и после технической валидации.

## Результат отрицательного испытания

Пробный прогон: https://github.com/kaokshi/kaokshi.github.io/actions/runs/44906504887

- Offline schema tests: 4 из 4 прошли.
- Пара исходный кадр / исправленная версия Klein: `needs_independent_validation`; все 6 флагов Qwen=True. Это **не** автоматическое одобрение.
- Заведомо несовпадающая пара — оригинальная сцена 2 и сцена 3 вместо её исправленной версии: `reject_candidate`, все шесть флагов False, выявлено расхождение.
- Это полезная начальная проверка, **но выборка из двух сравнений недостаточна**, чтобы утверждать надёжность по сложным ложным совпадениям, геометрическим дефектам или научным рисункам.
- Тарифная безопасность: только подтверждённый Workers Free; нет системной проверки текущего Neurons usage.
