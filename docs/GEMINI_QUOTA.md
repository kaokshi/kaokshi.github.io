# Gemini — видимость квот и независимая редактура

## Текущий технический статус

Gemini 3.5 Flash-Lite (`gemini-3.5-flash-lite`) добавлен в код как **второй, независимый редактор** после Groq. В отличие от OpenRouter, Gemini не используется как автор и не подменяет Groq при недостатке его квоты. Редакционная проверка первоначального и исправленного текста и право согласования владельца сохраняются. При недоступном Gemini статья получает `partial_review_pending` с причиной; полноценная независимая редактура не засчитывается.

**Автоматическая генерация Gemini намеренно заблокирована до подтверждения квот проекта и бесплатного тарифа.** Это не означает, что подключение не работает: только к реальным запросам `generateContent` применяется отдельный шлюз. Список моделей уже можно читать без генерации.

## Что нужно, чтобы разблокировать Gemini

1. В [Google AI Studio → API Keys](https://aistudio.google.com/api-keys) определите **проект, к которому относится `GEMINI_API_KEY`** в GitHub Actions. Лучше использовать отдельный проект только для редакции, без связанных платных биллинговых источников. **Не создавайте второй ключ в том же проекте, ожидая дополнительных лимитов**.
2. В [Rate Limits](https://aistudio.google.com/rate-limit) выберите этот же проект и точную модель `gemini-3.5-flash-lite`. Выпишите реальные **RPM**, **TPM (input)** и **RPD**, а также подтверждение уровня **Free**. В [Usage](https://aistudio.google.com/usage) посмотрите расход. Скриншота без ключей достаточно.
3. Если проект действительно отдельный и без платного биллинга, внесите в `config/editorial_production.json` внутри `gemini_quota_guard` подтверждённые числа: `verified_free_daily_requests`, `verified_free_rpm`, `verified_free_tpm`; дату `limits_confirmed_until` (не позже 30 дней после проверки), `exclusive_free_project_confirmed:true`, `automated_generation_enabled:true`, `mode:"second_editor"`. И в `schedule.gemini_free_only` установите `true`. Это изменение должно пройти Pull Request и изолированные проверки. До него система **не вызывает Gemini для генерации**.
4. Контроль `src.editorial_gemini_guard.py` сверяет разрешённую модель, фактическую её видимость через `models:list`, подтверждение бесплатного проекта и внесённые лимиты. Перед каждым вызовом проверяется консервативное минутное потребление. Бюджет: **не более двух вызовов Gemini на одну статью и четырёх в редакционном цикле** (производственные счётчики GitHub); предусмотрен резерв. HTTP 429/401/403 прекращает запросы без платного fallback.
5. **Реальный тест редактирования** делать только после шагов 1–4, сначала на изолированной синтетической фикстуре, без выпуска статьи. Если ответ усечён или API не подтвердил бесплатную квоту — фиксировать блокировку.

## Дополнительно: автоматическое чтение через Google Cloud Monitoring

Параллельно с основным API, workflow `.github/workflows/gemini-quota.yml` поддерживает необязательное **только чтение** Cloud Monitoring. Это не включает Cloud Billing и не повышает тариф.

1. В Google Cloud Console выберите тот **самый проект**. Создайте сервисный аккаунт только для диагностики с ролью `roles/monitoring.viewer`.
2. Настройте Workload Identity Federation для GitHub Actions: ограничьте доверие `kaokshi/kaokshi.github.io` и `refs/heads/main`. Дайте соответствующему principal только `roles/iam.workloadIdentityUser` на этот диагностический сервисный аккаунт. **Не создавайте JSON-ключ сервисного аккаунта**.
3. Добавьте в GitHub Actions Secrets `GOOGLE_WIF_PROVIDER` и `GOOGLE_QUOTA_VIEWER_SA_EMAIL`, в Actions Variables `GOOGLE_QUOTA_MONITOR_PROJECT` (ID проекта). Gemini API-ключ уже использует `GEMINI_API_KEY`.
4. Запустите [Gemini API access and quota visibility](https://github.com/kaokshi/kaokshi.github.io/actions/workflows/gemini-quota.yml). Отчёт отдельно покажет статус `models:list` и статус Cloud Monitoring. Он безопасно показывает лишь агрегированные сведения о метриках.

Контрольный запрос читает типы `generativelanguage.googleapis.com/quota/generate_content_free_tier_requests/usage` и `.../limit` за текущие тихоокеанские сутки. Метрики могут отсутствовать, запаздывать или быть недоступны на Free-уровне (например, HTTP 403). **Ни одно частичное значение не считается официальным балансом проекта и не разблокирует генерацию автоматически.**

## Как корректно трактовать остатки

- Квоты **на проект**, а не на один API-ключ. Другие приложения с ключами того же проекта тоже используют квоту.
- RPM, TPM и RPD считаются отдельно; исчерпание любого параметра блокирует генерацию.
- Дневной RPD **сбрасывается в 00:00 Pacific Time** (с переходом на летнее время), не в 00:00 UTC или МСК.
- `models:list` не сообщает оставшиеся лимиты. Даже если возвращает десятки моделей, они не обязательно доступными для конкретного бесплатного `generateContent`.
- Локальный журнал работы нашей редакции является **оценкой собственного потребления**, не учётом сторонних клиентов и не финансовой гарантией.
- **Нельзя подключать платный тариф или использовать billable-проект** без новой явной команды владельца.

Ссылки на документацию: [Rate limits](https://ai.google.dev/gemini-api/docs/rate-limits), [Pricing](https://ai.google.dev/gemini-api/docs/pricing), [Cloud Monitoring quotas](https://cloud.google.com/monitoring/alerts/using-quota-metrics).

## Безопасность существующей редакции

Публикация и RSS всё ещё заморожены, `config/site.json:publication_enabled=false`. Текстовые материалы и изображения по-прежнему производятся **только редакционным агентом** после разрешённых проверок; ни ChatGPT, ни Codex не вносят творческие правки. OpenRouter удалён из рабочего контурa. Данные API-ключей не помещать в Git, issues или чат.
