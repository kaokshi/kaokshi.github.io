# Большие жанровые корпуса — реальный поиск и запущенные эксперименты

**Дата:** 20.11.2026. **Решение владельца:** вместо обучения мистики на обычных эссе и кино на коротких рецензиях использовать достаточное число длинных жанровых текстов с явными метками. Избегать ложных заявлений о независимой достоверности авторства и достаточности данных.

## Запущенное исследование по мистике

- [Длительное обучение на 400 примерах](https://github.com/kaokshi/kaokshi.github.io/actions/runs/44733328060) в PR #12; скрипт `src/editorial_genre_train_legends.py`, workflow `.github/workflows/editorial-legends-longform-train.yml`.
- 100 human + 100 AI в **train**, 100 + 100 в **исследовательском holdout**; реальные четыре детектора (ruBERT v4, ModernBERT, LightGBM, AI Accent Detector), затем логистический стекер только исследовательского назначения.
- Исходные литературные тексты хранятся лишь временно внутри GitHub Actions runner. В репозиторий/ZIP и артефакты сохраняются только коэффициенты, хеш/версия корпуса, агрегаты, коэффициенты ошибок и индексы двух тестовых статей, но НЕ сами тексты.
- **ОГОВОРКИ:** human/AI по издательским меткам, пары не связаны одним сюжетом/автором, жанровые ключевые слова ≠ проверенные мистические рассказы, авторские группы не известны, раздельность от обучающих данных четырёх базовых детекторов не доказана. Это НЕ независимая валидация, не подтверждение точности, не разрешение публикации.
- Порог **строго >30** — только исследовательская оценка до отдельной независимой валидации. Конфиг `config/ai_revision_policy.json`, `publication_enabled`, статьи/RSS остаются без изменений.

## Реальная работа по оставшимся жанрам

1. Для научпопа нужен большой разрешённый для предполагаемой коммерческой системы корпус **русских научно-популярных** статей и известные ИИ-генерации, без неконтролируемых гуманитарных/академических замен; N+1 использовать только с учетом лицензии. Сформировать исходно независимые train/calibration/holdout группы.
2. Для кино нужны русскоязычные длинные сюжетные пересказы; достаточных проверенных human/AI примеров пока нет, нельзя заявлять, что тысячи зрительских отзывов заменяют пересказы. Нужна отдельная разметка и подтверждение происхождения.
3. Когда наборы собраны, запускать обучение через четыре детектора с реальными результатами, затем отдельное независимое финальное испытание минимум **120 human + 120 AI** по каждому жанру. Внешние метки, группировка и 95%-е доверительные границы обязательны.
4. Не публиковать статьи автоматически и не активировать порог на основании успешного исследования.

**Результаты длительного запуска перепроверять по GitHub Actions; факт старта не равен успешному обучению.**
