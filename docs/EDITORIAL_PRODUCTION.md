# Производство материалов для согласования

ZEN CONTROL принимает задания и хранит настройки управления. ZEN CORE ведёт задания, этапы, бюджет и восстановление. Облачная очередь передаёт только подтверждённые задания и возвращает приватные статусы. Точка входа исполнителя — `python -m src.editorial_zen_executor`. Поля контракта, команды и переходы описаны отдельно. [ZEN CORE / RouterAI](ZEN_CORE_ROUTERAI.md) · [ZEN CONTROL 1.0](ZEN_CONTROL_RELEASE_1.md)

## Маршрут и проверки

| Модель RouterAI | Задача |
| --- | --- |
| Qwen 3.6 Plus | Планирование, задания на кадры, смысловой визуальный контроль |
| Claude Sonnet 5.5 | Подготовка текста |
| DeepSeek V4 Pro | Независимая редактура |
| Seedream 5.0 Flash | Художественные иллюстрации, когда для позиции требуется генерация |

Текст проходит проверки структуры, грамотности, повторов и фактов. Научпоп использует проверенные фотографии с подходящими правами, программные схемы и художественные иллюстрации по месту. Смысловой контроль оценивает изображение по разделу статьи. Сюжетная смена локации допустима. Сходство и повторы проверяются по хешам и визуальным признакам. Для выпуска необходимы подтверждённые права на изображения. Киноканал сохраняется на паузе вместе с материалами и инструментами проверки. [Редакционный регламент](EDITORIAL_AUTOMATION.md) · [Проверки текста](EDITORIAL_AI_CHECKS.md)

## Управление, расходы и восстановление

- В ручном режиме владелец подтверждает следующий этап. Полуавтономный режим запрашивает подтверждение на границах иллюстраций и сборки. Автономный режим продолжает до блокировки или приватного пакета. Во всех режимах сохраняются аварийная пауза и проверки перед оплатой.
- Основной лимит составляет **300 ₽ в сутки по Москве**, резерв **50 ₽** доступен только для завершения начатых статей. Действует скользящий лимит **9 000 ₽ за 30 дней**. Для позиции иллюстрации предусмотрено до двух повторных попыток. ZEN CONTROL получает остатки и причины использования резерва.
- Приватный реестр хранит статусы, расходы и идентификаторы операций. Повтор запуска использует сохранённый ответ или принятый материал. Неизвестный исход оплаченной операции блокирует повтор и требует сверки. Исторические шифрованные пакеты и реестры читаются по отдельным архивным маршрутам. [Хранение и выдача](PRIVATE_EDITORIAL_STORAGE_SETUP.md) · [Вывод прежних провайдеров](LEGACY_PROVIDER_RETIREMENT.md)

## Действующие предохранители

`config/zen_core.json` хранит параметры исполнителя, включая выключенные флаги фактического исполнения, публикации и RSS. Облачная очередь также требует отдельных разрешений GitHub Actions. `config/editorial_production.json` содержит проверенные домены источников и адрес приватного хранилища исторических пакетов. Ключи и токены хранятся в секретах окружения. Изолированный ручной пилот RouterAI сохраняется под собственными ограничениями до проверки рабочего маршрута. [Политика выпуска](PUBLICATION_FREEZE.md)

Офлайн-регрессия выполняется через `Editorial and storage regression` и `ZEN CORE offline tests` с синтетическими данными и подменёнными транспортами. Workflow `ZEN CONTROL guarded deployment` требует отдельного запуска и подтверждения для обновления Worker. [Правила развёртывания](ZEN_CONTROL_RELEASE_1.md)
