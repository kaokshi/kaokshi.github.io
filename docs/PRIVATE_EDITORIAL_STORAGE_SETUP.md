# Приватное хранилище редакции

ZEN CORE хранит задания, этапы, расходы и ссылки на принятые материалы в `zen-core/v1/ledger.sqlite` приватного репозитория `kaokshi/zen-editorial-review`. Сохраняемые отдельно ответы и материалы привязаны к контрольным суммам. Исполнитель проверяет приватность репозитория и использует сверку предыдущей версии реестра перед записью. [Контракт ZEN CORE](ZEN_CORE_ROUTERAI.md)

## Доступ

- `EDITORIAL_PRIVATE_TOKEN` хранится в доверенной среде GitHub Actions. Для текущего исполнителя токен ограничивается приватным репозиторием с `Contents: Read and write`.
- Для зашифрованных архивов редакции сохраняются 32-байтовый `EDITORIAL_STATE_KEY_HEX` и открытая X25519-часть в `config/editorial_production.json`, поле `storage.owner_public_key`. Приватный X25519-ключ хранится только у владельца.
- Приватные копии для согласования хранятся с отдельными правилами доступа и срока видимости. [Доставка владельцу](CHATGPT_PRIVATE_DELIVERY.md)

## Восстановление

Для исторического комплекта используйте `python -m src.editorial_delivery retrieve` на доверенном компьютере владельца. Укажите дату или локальный зашифрованный артефакт, закрытый ключ и отдельную выходную папку. `storage.private_repository` задаёт источник по умолчанию. Выпуск и RSS управляются независимо от доступа к файлам.

В `Editorial and storage regression` синтетический комплект создаётся одним runner и проверяется другим. Тест открывает DOCX и HTML, сверяет изображения и SHA-256 пакета. Предыдущая разовая проверка подключения к хранилищу завершена. Штатный preflight ZEN CONTROL проверяет привязки перед развёртыванием с отдельным подтверждением. [Развёртывание и откат](../telegram-control/README.md#read-only-upgrade-preflight-and-rollback)
