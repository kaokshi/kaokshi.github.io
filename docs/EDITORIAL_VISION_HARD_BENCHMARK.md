# Визуальный контроль: второй, более сложный набор испытаний

Дата: 21.11.2026

## Почему потребовался второй тест

В первом наборе на 24 программно изменённых кадрах Qwen дала 23 правильных ответа и **1 опасный ложный допуск**: сильное кадрирование первой сцены ошибочно признано допустимым.

Первый набор: https://github.com/kaokshi/kaokshi.github.io/actions/runs/44907087391

## Исправление проблемы

`src/editorial_image_guardrails.py` добавляет независимую детерминированную проверку агрессивного **центрального кропа** при одинаковых размерах исходника и кандидата. Она сравнивает кадр с несколькими масштабами центрального участка исходника; при сильном совпадении с кропом и расхождении с оригиналом блокирует результат.

Ограничение: такой тест **не работает**, если у Klein меняется соотношение сторон (например, 1024×1024 → 1280×720), и должен возвращать `abstain`. Он **не является** универсальным детектором изменённой композиции. Используется Pillow лишь для аналитического теста, **не для визуальной обработки**.

## Научпоп: точные подписи по источникам

`src/editorial_science_vision.py` разделяет две разные задачи:

- Qwen получает реальные пиксели и переписывает только **то, что видит**: порядок подписанных планет либо пары символов ДНК. Не должна «исправлять» изображение по знаниям.
- Детерминированный код сверяет увиденные подписи с проверенным независимым источником. Для порядка первых планет — NASA https://science.nasa.gov/solar-system/planets/ ; для пар оснований ДНК — NHGRI https://www.genome.gov/about-genomics/fact-sheets/Deoxyribonucleic-Acid-Fact-Sheet .

Даже совпадение этих подписей не доказывает правильность всех научных схем: расположение, пропорции, масштаб и элементы могут оставаться некорректными. Пока вся автоматическая оценка — только **предварительный аудит**, `semantic_verified=false`.

## Второй бенчмарк

Скрипт `src/editorial_vision_hard_benchmark.py` сравнивает **8 пар** реальных FLUX.1 Schnell и FLUX.2 Klein изображений (включая старую скамейку, исходные и отредактированные коридоры, подмену сцен), из которых 6 размечены и 2 слишком неоднозначны для бинарной оценки.

Дополнительно программа делает **8 демонстрационных научных схем**, 4 с правильными и 4 с заведомо переставленными надписями, для NASA и NHGRI контрактов. Это искусственно составленные тестовые схемы, а не 8 реальных научных иллюстраций из журналов. Не использовать тестовые материалы в публикациях.

Run: https://github.com/kaokshi/kaokshi.github.io/actions/runs/44909886101

Риск: проверяющая Qwen обслуживается из той же бесплатной Workers AI квоты, что FLUX; точный расход Neurons на запросы из GitHub API не наблюдается. Нет публикации или платного fallback.

## Требования перед автономным утверждением

- Проверить надёжность на действительно независимых сложных реальных кадрах, не только на повторных композициях и программных трансформациях.
- Для фото проверять источник, лицензию, реальность научного утверждения; для схем научная экспертиза нужна помимо OCR.
- Одобрение не разрешать автоматически до проверки ложных допусков по каждой категории ошибок.
