# Model F4 — исследовательское сравнение с Model A

Дата начала: 20.11.2026. Только эксперимент на десяти имеющихся исходных статьях.
**Не менять производственную Model A, порог >80, RSS, публикацию и ветки Codex.**

Состав:
1. Fast-DetectGPT — академический исходный код, модельное сравнение с большим потреблением памяти. Для практического запуска необходимо выбрать совместимые scoring/sampling модели и проверить границы допустимой длины русского текста. **Не запускался в этом исследовании**, пока нет подтверждённого подходящего GPU и сопоставимого русскоязычного порога. Официальный репозиторий: https://github.com/baoguangsheng/fast-detect-gpt
2. Desklib AI Text Detector v1.01 — MIT, исходно обучен на английском. Скрипт `research/model_f4_desklib.py` запускает настоящий локальный inference на CPU GitHub Actions, режет длинный русский текст по токенам, фиксирует отдельно значения фрагментов и их неоткалиброванное среднее. Проверки 10 текстов жёстко сверяются с SHA-256 уже выполненного Model A. Результаты отчёта нужны **после** завершения CI. https://huggingface.co/desklib/ai-text-detector-v1.01
3. Binoculars — два больших Falcon-7B (оригинальный порог под эту пару, сильнее для английского); требует значительно большей памяти, чем стандартная бесплатная машина GitHub Actions; **не запускался**. https://github.com/ahans30/Binoculars
4. Linda — русский язык заявлен, бесплатное использование только некоммерческое; платная лицензия для коммерческого проекта. **Без отдельного подтверждения разрешённых условий использования не запускать**. https://github.com/Lendarixon/Linda

Сравнение результатов **не является тестом точности**: пока нет русскоязычной размеченной выборки человеческих и машинных текстов. Не усреднять нативные оценки разных моделей в псевдовероятность. Называть Model F4 лишь экспериментальной панелью из четырёх методик, а не новым пороговым критерием.

Исходный Model A: https://github.com/kaokshi/kaokshi.github.io/actions/runs/44765621268

Текущий статус: только Desklib интегрирован для настоящего экспериментального прогона; другие методы требуют ресурсной/лицензионной оценки. Не выдавать отсутствие результата за 0. Отдельный PR не объединять.
