# RouterAI — Claude Sonnet 5.5 автор, DeepSeek V4 Pro независимый редактор

> Архив раннего пилота. Текущий производственный маршрут и роли описаны в контракте ZEN CORE. [Действующая инструкция](EDITORIAL_PRODUCTION.md)

Интеграция в коде уже добавлена, но **платная генерация пока выключена**: `config/editorial_production.json` содержит `routerai_editor.enabled=false`, а GitHub workflow устанавливает `EDITORIAL_ROUTERAI_EDITOR_ALLOWED=false`. Смена этих полей без контроля баланса и суточной резервации бюджета **запрещена**.

## Подключение

1. В [RouterAI → API-ключи](https://routerai.ru/settings/api-keys) создать обычный API-ключ, предназначенный для нашей редакции. Код со страницы API (пример с `import requests`) в Secrets вставлять не нужно.
2. В [GitHub Actions Secrets](https://github.com/kaokshi/kaokshi.github.io/settings/secrets/actions) добавить единственный секрет `ROUTERAI_API_KEY`, значение — секретная строка ключа RouterAI. В чат и GitHub-код её не присылать.
3. Модели зафиксированы в `src/editorial_providers.py` как `anthropic/claude-sonnet-5.5` для автора и `deepseek/deepseek-v4-pro-0813` для проверяющего, API endpoint `POST https://routerai.ru/api/v1/chat/completions`; заголовок `Authorization: Bearer <secret>`. Формат совместим с OpenAI Chat Completions, SDK `requests` не нужен.
4. После разрешённой активации Claude Sonnet 5.5 пишет `draft`, а DeepSeek V4 Pro 0813 независимо редактирует `full-edit`. Пока маршрут заблокирован, продолжает действовать прежняя Groq-схема. Оценка исходной и отредактированной версии остаётся у внутренней системы QA; публикация без согласования не производится.
5. Бюджет-цель — **150 ₽/сутки** и **4500 ₽/30 дней**, до двух запросов каждой модели на статью, до четырёх запросов каждой модели на цикл. Это **пока конфигурационные цели, а не действующее ограничение расходов**. Не менять `enabled`/ `EDITORIAL_ROUTERAI_EDITOR_ALLOWED` до реализации и тестирования надёжного preflight: чтение текущего баланса с RouterAI, подтверждение стоимости конкретного запроса, долговечная (между запусками GitHub) резервация дневного бюджета и итоговая сверка фактического списания. Локальный подсчёт токенов сам по себе не гарантирует жёсткого денежного лимита; ещё один API-клиент может менять баланс.
6. После реализации guard сначала провести только безопасную проверку ключа/баланса без генерации и один ограниченный синтетический тест при подтверждённом платёжном пределе. Сохранить в приватном журнале расход в рублях; при сетевой ошибке, нехватке баланса или неизвестной цене **не делать запрос**.

Отдельная инфраструктура Gemini и Cloudflare не удаляется. OpenRouter снова не подключается.

См. [RouterAI быстрый старт](https://routerai.ru/docs/guides/overview/quickstart) и [описание модели](https://routerai.ru/models/anthropic/claude-sonnet-5.5).

## Бюджет с резервом (23 ноября 2026)

Расчёт по отображавшимся тарифам RouterAI: Claude Sonnet 5.5 (213 ₽/1M input, 1068 ₽/1M output), DeepSeek V4 Pro 0813 (19 ₽/1M input, 59 ₽/1M output). При 8k/5k токенов на создание и 10k/4k на редактуру получается около 7,47 ₽ на материал, 14,94 ₽ за два. Повторные проходы, более длинный контекст, дополнительные/скрытые токены рассуждения и фактический провайдер могут изменить стоимость. 150 ₽/сутки и 4500 ₽/30 дней — **целевой совместный потолок**, не проверенная гарантия в RouterAI. Лимит запросов/токенов и защищённый финансовый предохранитель должны быть реализованы до включения `enabled=true`.

## Три роли и совокупный бюджет

- Claude Sonnet 5.5: основной автор и при необходимости доработка.
- DeepSeek V4 Pro 0813: независимая редактура и логическая проверка.
- Qwen 3.6 Plus: мозг проекта, темы, план изображений и задания.

Совместный целевой бюджет **150 ₽ в день, 4500 ₽ за 30 дней**. Расчёт для двух статей при двукратной правке и ~16 агентных вызовах: около 37 ₽/сутки на типовых контекстах, запас ~4x. Это не настоящая защита списаний, пока нет проверенного удалённого лимита и журнала баланса. Для начального теста достаточно **1000 ₽ пополнения без автоплатежа**, но не включать paid mode, пока не подтверждён предохранитель.
