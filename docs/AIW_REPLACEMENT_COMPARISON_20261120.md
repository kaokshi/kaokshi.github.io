# Сравнение замен ruBERT v4: эксперимент 20.11.2026

В оригинальном рабочем контуре `ruBERT v4` **не отключён**. Эксперимент не влияет на редакцию и её публикацию.

## Две воспроизводимые CPU-связки

- Вариант A: ModernBERT + LightGBM + `toiletsandpaper/russian-ai-text-detector-bert` (имя CLI `transformer`).
- Вариант B: ModernBERT + LightGBM + `toiletsandpaper/russian-ai-text-detector-mini-frida` (`mini-frida`).
- AI Accent Detector сохраняется в каждом прогоне **отдельным стилистическим сигналом**: смешивать его численно с оценками ИИ-авторства некорректно.

Итоговый **неоткалиброванный индекс** у каждого варианта = арифметическое среднее **трёх** чисел (в шкале 0–100) от ModernBERT, LightGBM, нового кандидата. Это не процент текста, написанного ИИ, не оценка ZeroGPT и не научная оценка вероятности. Две модели и кандидаты обучены на пересекающемся LLMTrace: сигналы не независимы, а такое усреднение полезно лишь для предварительного описательного сравнения. Другие веса нельзя выдавать за проверенную калибровку.

## Какие модели **не запускаем** и почему

- Linda Loupe / Assay: лицензия только для личного некоммерческого применения; наш проект допускает коммерциализацию. Без лицензии даже локальный коммерческий эксперимент не согласовывается. https://github.com/Lendarixon/Linda
- GigaCheck Multi: 7B параметров и стандартная демонстрация GPU; 14 ГБ диска и бесплатный runner не дают оснований обещать работоспособность. https://huggingface.co/iitolstykh/GigaCheck-Detector-Multi
- SlopTotal исключён по явной команде владельца.

## Репликация

Workflow `.github/workflows/compare-aiw-replacements.yml` работает при PR в исследовательской ветке: ставит разрешённые веса на GitHub Actions, проводит **реальный** inference 11 исходных статей, печатает `MODEL_COMPARISON` и формирует JSON-артефакт `two-free-model-replacement-indices`.

При любой недоступной модели результат этого варианта `null`, без выдуманного числа; запуск должен завершиться ошибкой. Для точного сопоставления с ручным ZeroGPT потребуются совпадающие входные тексты и их SHA-256; ручные наблюдения владельца — 9 нулевых, 1 пятипроцентное, 1 23-процентное из 11 документов.

Без независимого теста с реальными человеческими и ИИ-материалами новые варианты нельзя объявлять точнее ruBERT, а показатели ZeroGPT использовать для обучения моделей не следует. Порог 15% в ZeroGPT — внешний ориентир для сравнения, не валидированный порог нового индекса.

**Никаких изменений** ruBERT в main, статьи, сайт, RSS, разрешения публикации, веса существующего ансамбля или регламент, и никакого включения кино. Только исследовательский PR.
