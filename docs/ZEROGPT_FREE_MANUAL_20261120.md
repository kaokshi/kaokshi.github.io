# Бесплатная проверка ZeroGPT: ручной маршрут без API

Дата: 20.11.2026. Исследовательская ветка, только чтение.

## Результаты исследования

- Официальный сайт https://www.zerogpt.com/ позволяет вставлять текст и предлагает Upload File; FAQ подтверждает поддержку TXT, DOCX и PDF с текстовым слоем.
- Условия https://www.zerogpt.com/terms-of-use запрещают автоматизированные системы для доступа к сервису без официального API или письменного разрешения. Поэтому **никакого Selenium, Playwright, scraping или прямого вызова недокументированных endpoint**.
- Бесплатно автоматизируем подготовку, но **не внешнюю отправку или считывание ответа**. Использование других сервисов с похожими названиями не является проверкой оригинальным ZeroGPT.com.
- Показатели детекторов не подтверждают авторство и не являются разрешением на публикацию; результаты ZeroGPT нельзя использовать как ground truth для обучения собственной модели.

## Действия

1. Запустить GitHub Actions `Prepare free manual ZeroGPT review (no API, read-only)` с точным slug нужной статьи.
2. Скачать artifact `zerogpt-manual-packet`, хранится один день. Он содержит TXT и JSON manifest с хешем текста, без вымышленного AI-результата.
3. Открыть https://www.zerogpt.com/ в браузере, вручную вставить TXT или загрузить файл и нажать Detect Text; записать показанный процент, дату и название статьи.
4. Сохранить результат в редакционной таблице вместе с SHA-256 из manifest. Если изменился исходный текст, выполнить подготовку и проверку заново.
5. Публикацию, RSS, четыре штатных AI-детектора, пороги и права на изображения **не менять**.

## Данные пользователя от 20.11.2026

Пользователь проверил полные DOCX-тексты и сообщил ZeroGPT: `legends-01-prohodnaya-17` = 0%, `science-08-sinie-ogni-idzena` = 5%, `cinema-01-truman-show-real-photos` = 0%. Эти числа **не получены программным прогоном**; статус: пользовательские наблюдения. Sapling тестировался на первых 1900 символах, поэтому прямое сравнение неприменимо.

## Ограничения

Workflow не подтверждает результат ZeroGPT. Доступность бесплатных проверок и лимиты зависят от актуальных условий сервиса. Нельзя автоматически подменять проверку другим сайтом, использовать платный API или заполнять `completed` без фактического результата.
