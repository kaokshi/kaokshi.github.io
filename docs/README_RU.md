# Автоматическая редакция Дзена — запуск

Три раздела сайта: кино, художественные городские легенды и научпоп. Генератор собирает HTML, RSS 2.0 и sitemap.

## Настройка GitHub Pages
1. Откройте https://github.com/kaokshi/kaokshi.github.io/settings/pages
2. В Build and deployment выберите **Source: GitHub Actions**.
3. Откройте вкладку Actions и запустите workflow **Publish editorial website** (если не запустился автоматически).
4. Адрес после успешного развёртывания: https://kaokshi.github.io

## Что происходит автоматически
При изменениях репозитория и по расписанию GitHub Actions запускает Python-генератор. Материал попадёт на сайт и в RSS только при наличии утверждённого JSON-черновика, записи времени публикации, редакторской проверки, подтверждения прав на изображения, подтверждённой редакторской проверки минимум двумя независимыми сервисами (поле `ai_reviewed: true`, список `ai_checks` с двумя разными поставщиками со статусом `completed`) и объёма текста не меньше 3000 символов без пробелов.

RSS: /feeds/cinema.xml, /feeds/legends.xml, /feeds/science.xml. Начальные ленты пустые. Публикация в Дзен НЕ включена до официального подтверждения RSS-подключения в Дзене.

## Формат JSON статьи
Файл content/articles/slug.json:

```json
{
 "channel":"science",
 "slug":"primer",
 "title":"Пример заголовка",
 "body_html":"<p>Статья минимум 3000 символов без пробелов, включая необходимые абзацы.</p>",
 "publish_at":"2026-12-01T12:00:00+03:00",
 "status":"draft",
 "editorial_reviewed":false,
 "rights_reviewed":false,
 "ai_reviewed": false,
 "ai_checks": [],
 "image_files":[]
}
```

Изменять draft → approved можно только после ручной редакционной проверки и решения вопросов авторского права. Не делайте это до фактического подтверждения. Фотографии должны быть сохранены в content/assets/ и иметь ссылки /assets/... в body_html; изображения утверждённых статей переносятся в site/assets.

## Добавление Word-статей
Предварительный импорт DOCX доступен в ранее выданном [архиве рабочего прототипа], но сам Word-импорт ещё не включён в этот репозиторий. Сейчас в `content/articles/` уже размещены черновики и ранее согласованные материалы, но это не означает разрешения их публиковать: глобальный флаг публикации выключен, а RSS не должен содержать записи до отдельной команды владельца. Следующий шаг — подключить реальные проверки несколькими сервисами, получить редакционное согласование и отдельное разрешение на выпуск.

## Безопасность и права
Не помещайте API-ключи в репозиторий. GitHub Pages публикует статические файлы. Не добавляйте к RSS изображения без соответствующих прав. Низкий процент детектора не гарантирует человеческое происхождение текста.

## Актуальные правила редакции
Подробный действующий регламент: [EDITORIAL_AUTOMATION.md](EDITORIAL_AUTOMATION.md). Старые одиночные поля `ai_score`, `ai_check_provider` и `ai_checked_at` в ранее подготовленных материалах сохраняются как исторические записи, но **не используются** как разрешение на публикацию. Техническая массовая проверка через API пока не подключена; ничего не отмечать как проверенное до реального выполнения проверок.
