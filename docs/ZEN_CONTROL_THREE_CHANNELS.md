# Три канала в приватной очереди

Управляющий агент ZEN CONTROL предлагает заказ. Владелец проверяет число статей и подтверждает его в Telegram. Для сквозной проверки нужен один подтверждённый заказ по две статьи на `cinema`, `legends` и `science`. Исполнитель использует штатные режимы, блокировку общих расходов и бюджет 300 ₽ в сутки по Москве с резервом 50 ₽ для завершения начатых материалов. Публичный выпуск и RSS остаются выключенными.

## Кино

В `zen-core/v1/sources/cinema.json` приватного хранилища находятся записи по Wikidata QID. У каждой записи указаны `title`, `original_title`, `year`, массив `stills` и при наличии редакционно проверенные `plot_sources`. Кадр содержит `original_title`, `year`, `scene`, `source_type` (`official_press` или `rights_holder`), `source_page`, `asset_url` и `sha256`. Для допуска фильма к планированию требуется семь разных исходных кадров. Код проверяет происхождение, идентичность фильма, хеш, повторы и соответствие каждого кадра разделу. Данные о правах на кадры не требуются для приватной сборки и помечаются `not_checked`. Правила публичного выпуска сохранены. Для научпопа и художественных иллюстраций действуют прежние проверки прав.

## DOCX и доставка

Сборка сверяет канонический текст в DOCX и HTML с проверенной версией. В DOCX встроены изображения с проверенными хешами. После успешной сборки `delivery/article.docx` и `delivery/manifest.json` сохраняются в приватном каталоге статьи `zen-core/v1/articles/<SHA-256 идентификатора статьи>/`. Файл извлекается владельцем из этого хранилища после сверки хеша. DOCX считается отправленным после квитанции Telegram для настроенного владельца.

`ZEN_CORE_TELEGRAM_DOCX_JOB` ограничивает отправку одним подтверждённым заказом `agent:<UUID>` и действует только в разрешённом приватном исполнителе. При неизвестном исходе отправки остаётся запись `sending` для сверки. Следующий проход очереди не отправляет файл повторно. Статусы сборки, принятые позиции и точные расходы по статьям остаются в приватном реестре.
