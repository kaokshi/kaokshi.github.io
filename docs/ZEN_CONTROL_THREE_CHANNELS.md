# Три канала в приватной очереди

Управляющий агент ZEN CONTROL предлагает заказ. Владелец проверяет число статей и подтверждает его в Telegram. Для сквозной проверки нужен один подтверждённый заказ по две статьи на `cinema`, `legends` и `science`. Исполнитель использует штатные режимы, блокировку общих расходов и бюджет 300 ₽ в сутки по Москве с резервом 50 ₽ для завершения начатых материалов. Публичный выпуск и RSS остаются выключенными.

## Кино

В `zen-core/v1/sources/cinema.json` приватного хранилища находятся записи по Wikidata QID. У каждой записи указаны `title`, `original_title`, `year`, массив `stills` и при наличии редакционно проверенные `plot_sources`. Кадр содержит `original_title`, `year`, `scene`, `source_type` (`official_press` или `rights_holder`), `source_page`, `asset_url` и `sha256`. Для допуска фильма к планированию требуется семь разных исходных кадров. Код проверяет происхождение, идентичность фильма, хеш, повторы и соответствие каждого кадра разделу. Данные о правах на кадры не требуются для приватной сборки и помечаются `not_checked`. Правила публичного выпуска сохранены. Для научпопа и атмосферных сцен мистики используются фотографии Wikimedia Commons с проверенными лицензиями и обязательной атрибуцией. Научпоп также использует схемы с привязкой к первичным источникам. Фильтрация кандидатов и Qwen проверяют кадр по разделу. Для авторских иллюстраций Seedream проверка маршрута и коммерческих условий сохраняется. [Оферта RouterAI, пункт 2.1.2](https://routerai.ru/terms/)

Каталог автоматически пополняется через `python -m src.editorial_cinema_catalogue`. Импортёр берёт видео, привязанное к Wikidata QID свойством P10, сверяет метаданные Commons и выбирает непохожие кадры с отметками времени. Двоичные файлы и контрольные суммы хранятся только в приватном репозитории. Отрывки, короткие трейлеры и материалы без распознаваемого статуса лицензии исключаются при подборе источника.

## DOCX и доставка

Сборка сверяет канонический текст в DOCX и HTML с проверенной версией. В DOCX встроены изображения с проверенными хешами. После успешной сборки `delivery/article.docx` и `delivery/manifest.json` сохраняются в приватном каталоге статьи `zen-core/v1/articles/<SHA-256 идентификатора статьи>/`. Файл извлекается владельцем из этого хранилища после сверки хеша. DOCX считается отправленным после квитанции Telegram для настроенного владельца.

`ZEN_CORE_TELEGRAM_DOCX_JOB` ограничивает отправку одним подтверждённым заказом `agent:<UUID>` и действует только в разрешённом приватном исполнителе. При неизвестном исходе отправки остаётся запись `sending` для сверки. Следующий проход очереди не отправляет файл повторно. Статусы сборки, принятые позиции и точные расходы по статьям остаются в приватном реестре.

Для сквозного прогона вручную запустите `ZEN CORE cloud queue and private executor` из `main` с `pilot_job` равным идентификатору подтверждённого в Telegram заказа. Пустой `pilot_job` выполняет только приём. Заказ должен содержать ровно две статьи каждого канала. Исполнение ограничено этим заказом даже при наличии других записей в очереди. Worker должен пройти preflight и запуск защищённого deployment с `enable_private_executor`. Публичные RSS и публикация проходят по отдельным отключённым контурам.
