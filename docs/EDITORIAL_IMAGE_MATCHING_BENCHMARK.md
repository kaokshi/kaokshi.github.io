# Сравнение смыслового подбора изображений

Экспериментальная ветка основана на [черновике PR №66](https://github.com/kaokshi/kaokshi.github.io/pull/66). Модели запускаются на CPU GitHub Actions без платных API. Отчёт и экспериментальный режим доступны в [черновике PR №70](https://github.com/kaokshi/kaokshi.github.io/pull/70).

## Методика

- Замороженный набор включает 30 изображений и 12 задач, по 10 изображений и четыре задачи на канал. Разметчик просмотрел изображения до получения ответов моделей. В каждой задаче зафиксированы описание сцены, обязательные признаки, возможные противоречия и метки «совпадение», «частичное совпадение», «нерелевантно». Частичное совпадение не засчитывается за точное. У научпопа задача про солнечное затмение проверяет различие между визуально близкими явлениями. Она добавлена как отдельный контроль к подборке архивных тем. [Манифест с SHA-256, подписями и источниками](../benchmarks/editorial_image_matching.json).
- Базовый CLIP выбирает первый кадр в исходном порядке, прошедший действующие пороги, 0,19 для описания сцены и отрыв 0,015 от нерелевантного описания. Дополнительный контроль ранжирует тот же набор по CLIP. SigLIP 2 оценивает все кадры по сцене и использует отрыв от конкурирующих описаний для разрешения равных результатов.
- Florence-2 формирует описание из пикселей для пяти кандидатов SigLIP 2. Проверка обязательных и противоречащих признаков работает по заранее заданным выражениям. При недостающем признаке агент может воздержаться. Название файла, подпись источника и текст запроса не подаются Florence‑2.
- Precision@1 показывает долю задач с правильным первым изображением. Отказ считается отсутствием попадания. Recall@5 показывает долю задач, где среди первых пяти выбранных есть хотя бы одно точное совпадение. Ошибочные допуски и отказы считаются по парам «сцена — изображение». При одном ранжировании допуском считается попадание в топ‑5. У базового CLIP допуском считается прохождение порога, у Florence‑2 — подтверждение обязательных признаков.
- Это небольшая выборка с одним разметчиком. Модельное описание может терять детали и ошибаться. Права использования, личность актёра, принадлежность кадра к фильму и научная достоверность требуют проверки по источникам.

## Модели и среда

| Режим | Контрольная точка | Лицензия |
| --- | --- | --- |
| CLIP | `openai/clip-vit-base-patch32@3d74acf` | MIT у кода OpenAI CLIP. В карточке контрольной точки HF явная лицензия не указана. [Код и лицензия](https://github.com/openai/CLIP/blob/main/LICENSE) · [карточка](https://huggingface.co/openai/clip-vit-base-patch32) |
| SigLIP 2 | `google/siglip2-base-patch16-224@75de2d5` | Apache 2.0. [Карточка](https://huggingface.co/google/siglip2-base-patch16-224) |
| Florence-2 | `florence-community/Florence-2-base@00921df` | MIT. Нативная версия Transformers, загружаемая без удалённого Python-кода. [Карточка](https://huggingface.co/florence-community/Florence-2-base) · [версия Microsoft](https://huggingface.co/microsoft/Florence-2-base) |

Использованы Python 3.12, PyTorch 2.11.0 CPU, Transformers 5.24.0 и два потока. Для каждой модели отдельно измеряются запуск, обработка набора и пиковый RSS процесса. Время сети на получение исходных изображений в инференс не входит. Каждый кадр Florence‑2 описывается один раз, даже если входит в несколько списков. Время базового CLIP в таблице относится к оценке всех кандидатов для расчёта метрик. В рабочем режиме поиск останавливается на первом прошедшем порог кадре.

## Воспроизведение

Запуск `Editorial image matching experiment` вручную с ветки `codex/editorial-image-matching`. Артефакт `editorial-image-benchmark` хранится 14 дней. Его JSON содержит оценки, решения по кандидатам, SHA-256 и замеры. Контактный лист содержит только разрешённые для повторного использования миниатюры с отдельным файлом атрибуции. Для кадров кино выводятся идентификаторы и источники.

## Реальный запуск

Один запуск завершил все три модели и проверку архивной статьи. В первом запуске контрольная точка Florence‑2 загрузилась, но процесс превысил лимит в восемь минут после загрузки. В успешном запуске использовалось то же ограничение до 48 токенов на описание. Причина первого замедления не установлена. [Успешный запуск](https://github.com/kaokshi/kaokshi.github.io/actions/runs/45060932216) · [артефакт с контактными листами и JSON](https://github.com/kaokshi/kaokshi.github.io/actions/runs/45060932216/artifacts/14769611798) · [первый запуск с тайм-аутом](https://github.com/kaokshi/kaokshi.github.io/actions/runs/45060207830).

В 190 оценок входят задачи из 12 основных примеров и семь дополнительных сцен архивной статьи. Пять ошибочных первых изображений базового CLIP включают студийную декорацию вместо ночного автобуса, автобусную остановку вместо железнодорожной платформы, оконный проём вместо зеркала, вулкан вместо красного спрайта и выход Трумана в море вместо кадра с лестницей. Ранжирование CLIP исправило четыре случая, но первым для красного спрайта выбрало комету. SigLIP 2 поставил на первое место точные кадры во всех пяти случаях. Проверка Florence‑2 подтвердила платформу и зеркало, однако пропустила фары на подходящем кадре автобуса, признаки красного спрайта и лестницу у края декорации.

## Архивная статья «Шоу Трумана»

На неизменном тексте построена новая раскладка из того же замороженного набора. Реальные кадры фильма сравнивались с визуально близкими отвлекающими кадрами. В таблице «—» означает отсутствие подтверждённого уникального кадра либо отсутствие старого кадра. Расширенный JSON содержит описание каждой сцены, вывод Florence‑2, отдельные причины отказа, источник и сведения о правах для каждого старого и нового кадра. На подбор для архивной статьи ушло 8,12 с вычислений CLIP по всем кандидатам, 32,74 с вычислений SigLIP 2 и 17,49 с описаний Florence‑2. Итого для связки 50,23 с только на оценку. Время сбора источников, проверки прав и упаковки статьи сюда не входит. Из восьми ранее размещённых кадров подтверждены три. Новых пригодных кадров этот прогон не добавил. Права кино остаются в статусе `rights_review_pending`. Схема показывает идентификаторы кадров без повторного распространения изображений.

## Решение

Оставить текущий производственный режим. Из испытанных вариантов ранжирование имеющимся CLIP даёт наиболее дешёвое улучшение и исправляет четыре из пяти ошибок. SigLIP 2 подходит как независимое ранжирование спорных случаев после проверки на расширенной разметке. Обязательное подтверждение Florence‑2 сейчас слишком часто оставляет материал без подходящего изображения. Его описания можно собирать для диагностики конкретных расхождений.

Экспериментальный переключатель подключается к существующему поиску фотографий. Он получает уникальных кандидатов из Commons и NASA, сохраняет сведения об авторстве и лицензии, проверяет оригинал, пороги качества и повторы. При неподходящем наборе он указывает на поиск другого источника или разрешённую объясняющую иллюстрацию Klein. Сравнение не измеряло сквозную скорость этого сетевого режима или качество новых генераций. Результатов недостаточно для производственного переключения.
