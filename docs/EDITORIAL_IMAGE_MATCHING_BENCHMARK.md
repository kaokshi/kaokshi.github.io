# Смысловая проверка фотографий: эксперимент 23.11.2026

## Статус
Экспериментальная реализация. **Не объединять в main и не использовать оценки поисковых метаданных как доказательство качества**. Отдельный Draft PR к ветке `codex/editorial-production`.

### Реальная ошибка исходного кода
`src/editorial_images.py::photo` завершал поиск сразу после первого фото, прошедшего CLIP. Порядок выдачи NASA/Commons мог определять выбор, хотя поздний результат ближе к смыслу раздела.

### Исправление
- Загружается ограниченный пул до 20 фотографий NASA/Wikimedia.
- Фотографии предварительно ранжируются по отношению к конкретной сцене, с сохранением тематического индекса, вместо выбора первой подошедшей.
- Вся существующая итоговая проверка `ImageIndex.save` сохраняется: CLIP-барьер, разрешение, контраст, SHA-256, pHash, семантические повторы, метаданные лицензии и права.
- При отсутствии подходящего результата возвращается явный blocker, не тематическая подмена.
- Для кино действуют прежние отдельные механизмы `editorial_cinema.stills`, этот код не подменяет кадры фильма.
- Основная связка Groq, OpenRouter, Cloudflare Klein и публикационные флаги не меняются.

### Подтверждённые тесты
- Regression GitHub Actions: https://github.com/kaokshi/kaokshi.github.io/actions/runs/45052133084 — **3/3 пройдено**, фиктивные JPEG и управляемые оценки; доказывают только корректность кода выбора, не качество визуального понимания.
- Исследование на реальных фотографиях: https://github.com/kaokshi/kaokshi.github.io/actions/runs/45052278510 — отдельный CPU workflow, реальные модели CLIP `openai/clip-vit-base-patch32`, SigLIP 2 `google/siglip2-base-patch16-224`, Florence-2 `florence-community/Florence-2-base`; конечные результаты смотреть в артефакте `visual-models-weak-label-trial` после завершения, без автоматических утверждений об успехе.

### Методологические ограничения
- 30 изображений собираются из тематических поисков Wikimedia Commons; поисковый запрос использован как **слабая метка**. Такая метка может ошибаться, не является независимой разметкой. Доли совпадений между запросом и предсказанием — не Precision@1 и не доказательство уменьшения редакционных ошибок.
- Поиск не гарантирует 30 доступных качественных фотографий. Фактическое количество обязано отражаться в результатах.
- Florence генерирует описания для технической оценки, но они могут галлюцинировать.
- Для корректного сравнительного измерения качества требуется отдельный **человеком проверенный набор** из не менее 30 изображений с достоверными ссылками, принадлежностью к жанру, проверкой прав, правильным ответом и сложными близкими негативами.
- Недоступность моделей, отказ загрузки или превышение допустимых ресурсов должно отражаться как ошибка; не считать технический запуск подтверждением качества.

### Рекомендованное решение
**Не включать новую систему в производство автоматически.** После реального бенчмарка и независимой проверки разметки сравнить долю неправильных первых кадров, долю отклонений, скорость и память. SigLIP 2 и Florence-2 пока исследовательские компоненты, а не подтверждённая замена CLIP.

### Аудит
Публикация запрещена, никаких изменений RSS, платежей или ключей, фотографии бенчмарка не выкладываются в публичные артефакты.
