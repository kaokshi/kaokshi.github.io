## Текущий блокер и следующий тест

ModelScope API-Inference документирован как API с персональным access token.
Секрета `MODELSCOPE_API_TOKEN` в GitHub Actions на момент диагностики нет.
Публичный список моделей не заменяет доступ к API. **Запрещено** обходить
аутентификацию, перенаправлять вызовы ModelScope на Kilo под другим названием,
включать платные модели или отмечать сравнение успешным без реальных результатов.

После подключения токена — проверить (1) авторизацию и наличие нужной модели,
(2) бесплатность/фактические квоты до генерации, (3) аналогичные синтетические
JSON-тесты для обеих моделей, (4) полный агентский прогон по одному материалу
на канал, без Groq, (5) QA, текст, фото, авторские права, изображения, расход
и время в сопоставлении с основной схемой. Все черновики только в закрытом
хранилище, публикация и регулярные расписания отключены.
