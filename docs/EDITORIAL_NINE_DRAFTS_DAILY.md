# Ежедневная подготовка девяти статей

**Решение владельца от 20 ноября 2026:** три новых черновика каждый день на каждый канал: `legends`, `science`, `cinema`. Итого **9 в сутки**. Это **задание на подготовку**, а не разрешение публикации или доказательство пропускной способности локального Qwen.

Действует редакционный стандарт 3000–6000 символов без пробелов, Model A с рекомендательным >85, две агентские правки плюс максимум одна правка ChatGPT, доказательства по SHA-256, фактчекинг науки и кино, русский литературный стиль, иллюстрации для согласования. Ни RSS, ни публикация без отдельного разрешения владельца не запускаются.

## Как запускать

Нужен реальный локальный сервер Qwen (llama.cpp или Ollama), приватный каталог вне репозитория, установленные редакционные инструменты и доступ к первоисточникам. Сначала подготовить предложение тем:

```bash
python src/editorial_daily_topic_plan.py --date 2026-11-21 \
  --workspace "$HOME/.local/share/zen-editorial-private" \
  --provider src/editorial_local_llm.py
```

Результат `nine-topics-YYYY-MM-DD.json`: три разные темы для каждого канала и три поисковых запроса к научным источникам. На этом этапе модель **только предлагает темы**. Реальные сведения о фильмах и научные факты не подтверждаются генерацией плана.

Проверка очереди без обращения к модели:

```bash
python src/editorial_nine_draft_queue.py \
  --plan "$HOME/.local/share/zen-editorial-private/nine-topics-2026-11-21.json" \
  --workspace "$HOME/.local/share/zen-editorial-private" \
  --status-only
```

Реальный запуск той же команды **без** `--status-only` готовит до девяти досье. Одно некорректное задание или временный сбой не помечает остальные завершёнными. Для повторного запуска брать тот же план. Состояние записывается в `nine-draft-status-YYYY-MM-DD.json`.

## Почему не считаем автоматизацию завершённой

- На доступных GitHub CI проверены интерфейсы, логика сохранения, валидность очереди и защита от фиктивного успеха, но не продемонстрирована непрерывная генерация **9 полноценных новых статей** локальной Qwen за утреннее окно.
- Проверка фактов для кино пока включает обязательное **ручное** подтверждение точности сюжета и выбора спойлеров. Для научпопа отдельные первоисточники обязательны.
- Иллюстрации могут искаться без фильтра по лицензии, но по каждой выбранной иллюстрации нужно проверить фактическую пригодность и условия дальнейшего использования. Девять полных комплектов изображений ежедневно пока не подготовлены.
- Задачи ChatGPT на 08:00 и 11:00 МСК обновлены для **9 черновиков**, но это не означает, что подключён настоящий Qwen-исполнитель или что создан транспорт передачи приватных текстов из GitHub в диалог. Если транспорт недоступен, отмечать `not_connected`.
- В CI не загружать приватные черновики, иллюстрации или историю правок как публичные артефакты.

**Целевой контроль перед вводом редакции в рабочую эксплуатацию:** подряд несколько дней получать 9 реальных черновиков с отчетами, проверенными фактами и изображениями, и без сбоев доставлять их владельцу к 11:00 МСК. Пока это критерии готовности, а не выполненный факт.
