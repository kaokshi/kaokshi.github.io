# Эксперимент: проверяющие модели → новая генерация Klein

**Статус:** тестовый код, не включён в рабочий режим. База: ветка `experiment/editorial-image-rerank-20261123` (PR №67), исходный редакционный агент PR №66.

## Что действительно добавлено

- `src/editorial_image_feedback.py`: локальный CPU SigLIP 2 ранжирует описание конкретной сцены относительно отвлекающего примера, Florence-2 описывает фактическое изображение.
- `repair_prompt`: формирует **новый text-to-image промпт**, содержащий целевую сцену, optional `must_include`, `must_avoid`, стилевые требования и текст описания предыдущей неудачной попытки. Klein здесь **не умеет править пиксели предыдущей картинки**, он генерирует новую.
- `src/editorial_images.py::generated`: если `EDITORIAL_IMAGE_FEEDBACK_EXPERIMENT=true`, делает до **трёх** генераций, повторно анализирует картинку, записывает согласованный вариант только после проверок. При недоступных моделях завершает с блокировкой. По умолчанию текущий производственный режим и 2 исходные попытки сохраняются.
- Финальный `ImageIndex.save` по-прежнему проверяет CLIP, дубли, качество и записывает права. Дополнительные модели **не заменяют** этот этап.
- Кино не меняется: настоящее киноизображение выбирает другой модуль, фальшивые кадры не генерируются.

## Чего пока нет — нельзя выдавать за готовое
- В этой ветке **пока нет реального полного замкнутого теста Klein → SigLIP2 → Florence2 → новый Klein → проверка**.
- Относительный score SigLIP2 с отвлекающей сценой — *не калиброванный показатель смыслового качества*. Florence-2 может ошибиться или не заметить важный объект. Поэтому автоматическая проверка не гарантирует точности.
- Optional обязательные элементы сцен должны поступать из проверенного планировщика; самостоятельное извлечение фактов из языка статьи не доказано.
- Средние затраты CPU и лимиты для всех восьми иллюстраций ещё не измерены.
- По прежнему требуется редакторская проверка картинки, прав и подтверждения научных деталей.

**Внедрение:** только после реального прогона с нулевыми платными вызовами, оценкой точности на проверенном наборе и согласования. Не сливать в `main`. Публикация и RSS остаются замороженными.
