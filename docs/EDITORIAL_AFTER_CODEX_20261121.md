## Что дополнительно исправлено после Codex

Отдельная ветка `fix/editorial-qwen-revision-target-20261121`, основание `audit/editorial-cloudflare-48`; draft PR №50. Никаких изменений непосредственно в PR №49 или PR №47/48.

**Корневая причина ошибки редактирования:** локальный адаптер `src/editorial_local_llm.py` ранее задавал открытый JSON schema для произвольных `issue_id`, номеров абзацев и числа `edits`. Даже корректно синтаксический ответ модели мог выбрать несуществующий или повторный абзац. Проверка `assistant_edit` отбрасывала такой ответ, расходуя редакционный бюджет.

**Исправлено:** для задачи `revise`, не являющейся resize, адаптер выбирает первое допустимое диагностированное замечание с существующим номером абзаца; передаёт провайдеру только его и формирует JSON schema с фиксированным `issue_id`, фиксированным `paragraph` и `maxItems=1`. `before` по-прежнему заполняется из оригинала. Возможность безопасного `edits=[]` сохранена. Модель не может менять абзац с другим номером при соблюдении JSON schema. Бюджет 2+1 и проверка текста не ослаблены.

Новые регрессии: `tests/test_editorial_qwen_revision_targets.py`:
- правильная адресная правка и восстановление before;
- неправильный номер отвергается;
- повторные правки одного абзаца отвергаются;
- пустой список является безопасным отказом;
- отсутствие подходящего замечания останавливает вызов до провайдера.
