# Дополнительная проверка читаемости и читательского интереса

Проект «Дзен — ИИ-редакция», пилот 21 ноября 2026. Все изменения исключительно редакционные: **не блокировать публикацию по формуле удобочитаемости**, не менять Model A (>85 рекомендательно), лимит 2+1 и блокировку RSS.

## Используемые проекты

- [ruTS](https://github.com/SergeyShk/ruTS), лицензия MIT: реальная локальная Python-библиотека. В `src/editorial_reader_interest.py` вызываются `BasicStats`, `ReadabilityStats`, `DiversityStats` по русскому тексту; результаты записываются отдельно, со статусом `not_installed` или `error`, если реальная проверка недоступна. Для красивой прозы высокий или низкий балл Флеша не означает высокое/низкое качество.
- [ru-text](https://github.com/talkstream/ru-text): внешний редакционный *скилл на статических Markdown-инструкциях*, не исполняемая локальная модель. Мы добавили собственные ограниченные, объяснимые правила с цитированием фрагмента, основанные на общей задаче вычитки и удаления канцелярита; **сам скилл не установлен и не выдаётся за запущенный**. Перед полной интеграцией Codex может отдельно установить сторонний скилл после проверки прав и содержимого.
- [russian-editor-skill](https://github.com/SingeltonAttero/russian-editor-skill): инструкции для содержательной редактуры, а не автоматический показатель интереса. В `src/editorial_semantic.py` добавлены собственные запросы к редактору оценивать зацепку, логический темп и конкретность без оценки «интересности в процентах». Реальная смысловая редактура требует подключённой LLM.

## Использование

```sh
python -m pip install ruts
python src/editorial_reader_interest.py \
    --article content/articles/legends-01-prohodnaya-17.json \
    --article content/articles/science-01-krasnye-spraity.json \
    --output /tmp/zen-reader-interest.json
```

Анализ каждой версии в `src/editorial_revision_checks.py` содержит `reader_interest`; замечания привязаны к SHA-256, но **не изменяют текст, не расходуют редакционные попытки и не выступают доказательством AI-авторства**. После полноценного использования LLM можно подавать локальные предупреждения агенту на обоснованное разбирательство, а не автоматически переписывать.

## Проверка готовности

CI запускает настоящую ruTS для 10 текстов и тесты интерфейса. Пилот не доказывает интересность статей читателю; для этого нужны качественные отзывы, тесты заголовков/вступлений и — после разрешённого запуска — статистика дочитываний. Отсутствие подтверждённой интеграции реальной LLM и транспорта согласования не позволяет называть редакцию автономной.
