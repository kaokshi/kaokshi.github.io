# Бесплатная полностью автоматическая диагностика ИИ — эксперимент, 20.11.2026

## Цель
Исключить ручное копирование/загрузку статей и расходы на ZeroGPT API. Базовый бесплатный контур GitHub Actions запускает четыре **уже интегрированных локальных** русскоязычных детектора и автоматически строит диагностический отчёт.

## Реализация
- `src/editorial_ai_check.py` уже исполняет ruBERT v4, ModernBERT, LightGBM, AI Accent.
- Новый `src/editorial_ai_auto_triage.py` автоматически читает настоящие отчёты текущего прогона, не отправляет черновики наружу.
- Workflow `.github/workflows/editorial-ai-checks.yml` после штатных проверок выполняет анализ и сохраняет 7-дневный артефакт `editorial-ai-triage`.
- Поведение: если не все четыре отчёта действительны, маршрут `human_editorial_review`; если разница между тремя классификаторами >=50 пунктов, флаг `editorial_attention`; если статья короче 3000 знаков без пробелов, флаг проверки длины.
- `AI Accent` сохраняется **отдельным стилевым показателем**, не смешивается с вероятностью ИИ-авторства.
- Даже согласие классификаторов **не** признаёт текст человеческим и не означает готовность публикации. Флаги требуют содержательной проверки, а не автоматического переписывания.
- Тесты `tests/test_editorial_ai_auto_triage.py` и `.github/workflows/editorial-ai-triage-tests.yml` проверяют логику без скачивания моделей.
- Никаких обращений к ZeroGPT, скрытым endpoint, браузерной автоматизации, платным API или новым сервисам.

## Исследование ZeroGPT / Sapling
Владелец сообщил результаты **на полных DOCX**: 0%, 5%, 0% соответственно мистика/научпоп/кино. Ранее Sapling проверял лишь 1900-символьные фрагменты и показал 86.6%, 100%, 99.9%. Разные размеры входа и модели — не доказательство, что один сервис точнее. Эти цифры не использовать как обучающие метки или подтверждение авторства.

## Что ещё НЕ сделано
- Новый анализатор **не заменяет полноценный автоматизированный редактор**: он формирует рекомендации, но не вносит правки.
- Отсутствует независимая валидированная точность моделей на всех жанрах, они остаются экспериментальными.
- Автоматический запуск всего проекта и настройка 2 статьи на каждый из 3 каналов не изменяются этим PR. `cinema` по действующему регламенту на паузе до отдельной команды; запланированные шесть текстов ежедневно не означают разрешение на выпуск.
- Изменения в экспериментальной ветке и PR, ещё не в `main`. Пока PR не объединён, новую автоматическую проверку нельзя считать производственной.
- Публикация, RSS и `publication_enabled=false` строго не меняются.

## Бесплатность
Стандартные GitHub-hosted runners для публичных репозиториев бесплатны согласно https://docs.github.com/en/billing/concepts/product-billing/github-actions ; использование тяжёлых моделей и ограничения GitHub Actions всё равно нужно отслеживать. Нет новых платных провайдеров или ключей.
