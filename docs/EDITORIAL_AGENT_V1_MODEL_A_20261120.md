# Дзен — ИИ-редакция: агент v1 и модель A (решение владельца 20.11.2026)

## Состав моделей
ruBERT v4 исключён из **новой экспериментальной цепочки**. `ModernBERT + LightGBM + AIW-RU BERT (CLI transformer)` → средний **диагностический индекс** (0–100); `AI Accent Detector` — отдельный стилевой сигнал. Это **не процент ИИ-авторства** и не ZeroGPT.

**Правило владельца:** только индекс **строго >80** направляет материал на редакционный осмотр и, при наличии конкретных подтверждённых недостатков, в процедуру доработки. Ровно 80 — не превышение. При ошибке модели или устаревшем отчёте — не объявлять проверку пройденной.

## Будущие роли редакционного ИИ-агента

1. **Главный редактор-оркестратор** — очередь, жанры, дедлайны, остановка неудачных циклов.
2. **Аналитик тем** — актуальные темы и оригинальные идеи, поиск повторов, кино пока на паузе.
3. **Автор** — оригинальный, естественный русский, смысловые блоки, >=3000 символов без пробелов и авторский CTA.
4. **Фактчекер** — первоисточники науки/кино, даты и факты; для мистики оригинальность и непротиворечивость.
5. **Иллюстратор / редактор прав** — 7–8 подходящих изображений, лицензии, ссылки и права; без заглушек и повторов.
6. **Корректор** — логика, дубли, канцеляризмы, LanguageTool/Vale, естественность русского.
7. **Модельный диагност** — четыре реальные локальные проверки, вычисление индекса A и детальные отчёты, хеш текста.
8. **Редактор доработок** — конкретные подтверждённые проблемы → максимум **две** реальные правки с полным повтором проверок.
9. **Эскалация в ChatGPT** — после двух **неудачных** попыток агентов ровно одна содержательная редактура и новая проверка; затем, если неудачно, пересылка владельцу.
10. **Упаковщик и доставщик** — DOCX, изображения и карточки на согласование в 11:00 МСК; до явного запуска только черновики.
11. **RSS / аналитика** — существующий GitHub Pages + RSS, включать только после отдельной команды владельца, позже анализировать просмотры и эффективность.

## Что пока не подключено (важно)

- Нет автономной генерации/реальной переписи текста агентами. Маршрутизатор создаёт задание **только в форме JSON**, а не выполняет его.
- Нет GitHub→ChatGPT handoff транспорта и подтверждения доставки пользователю. Нельзя выдавать `transport_status:not_connected` за доставку.
- Ранее согласованные ежедневные задачи 08:00/11:00 не переписаны под новую модель, пока не завершены тесты и интеграция. Следует привести их в соответствие после внедрения в `main`.
- Главная ветка пока не изменена, пока PR не слит. Публикация и RSS заблокированы, cinema не активируется.
- Данные 11 наших статей и ZeroGPT не подтверждают надёжность порога 80. Это добровольный редакционный триггер, не валидированная вероятность.
- Не отправлять текст в сторонние API. Не пытаться оптимизировать содержание ради обмана ИИ-детекторов.

## Передача между этапами

Для каждого материала: immutable SHA-256 очищенного текста, статусы тестов, ссылки на реальные отчёты, список конкретных замечаний, счётчик попыток и полный журнал того, что действительно менялось. Пустая редакция или старый отчёт не засчитываются. Без подтверждённой полноты проверок статья направляется на разбор, не в публикацию.

## Самообучение агента: принятое требование владельца 20.11.2026

Добавлена отдельная конфигурация `config/agent_learning.json` и правила для Codex в корневом `AGENTS.md`. Агент в будущем должен учиться **на результатах реальной редакторской работы**: подтверждённых замечаниях владельца, качественных исправлениях и их причинах, ошибках фактчекинга, результатах локальных тестов и, после официального запуска, на разрешённых показателях Дзена. Не сводить обучение к одному показателю AI-детектора.

Первая версия самообучения: накопление структурированных случаев → анализ повторяющихся ошибок по жанрам → **предложение** улучшений правил/промптов/моделей в отдельной ветке → независимая проверка без утечек обучающей выборки → одобрение владельца → возможное внедрение с откатом. Не обучаться на непроверенных текстах и не объявлять ZeroGPT эталоном истинного происхождения.

`enabled=true` — разрешение проектировать и собирать доказательства для этого контура, **не означает, что непрерывное дообучение уже технически запущено**. Самостоятельное изменение весов, порога Model A 80, порядка двух агентных + одной ChatGPT попытки, разрешений публикации и RSS запрещено. Для реального исполнения требуется отдельный исполняющий модуль и подтверждение работоспособности.
