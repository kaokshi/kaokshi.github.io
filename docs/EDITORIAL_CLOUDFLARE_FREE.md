# Cloudflare Workers AI: бесплатный режим иллюстраций

Экспериментальный адаптер в `src/editorial_cloudflare.py` и его подключение к `src/editorial_media.py` добавлены отдельно от основного PR №47.

## Безопасность и статус

- Этот PR **не включает публикацию** и не меняет конфигурацию сайта.
- `ZEN_IMAGE_PROVIDER=cloudflare` включает облачную генерацию только для канала `legends`. Для `science` остаётся Wikimedia Commons.
- По умолчанию по-прежнему используется `sd-webui`; облачные вызовы без явного переключения не выполняются.
- `ZEN_CLOUDFLARE_FREE_PLAN_CONFIRMED=true` обязателен. Владелец должен подтвердить **Workers Free**, а не просто наличие токена. Программно сервисный тариф не проверяется.
- `ZEN_IMAGE_ALLOW_PAID=false` обязателен: значение true блокирует работу. Это защитный переключатель **в нашем коде**, а не замена тарифному ограничителю Cloudflare. При платном тарифе код сам не способен гарантировать отсутствие начислений.
- Нет автоматического перехода на Modal или Runway. **Modal отключён**, пока не подтверждены реальные бесплатные кредиты и жёсткий запрет оплаты. GitHub Secrets Modal могут существовать без использования.
- Для каждой статьи по-прежнему нужен задокументированный законный режим использования изображения (`ZEN_GENERATOR_RIGHTS`). Не утверждать коммерческие права без проверки условий модели и провайдера.
- Не записывать токены, URL с секретами и сырые сообщения провайдера в логи.

## Что настроить на секретном runner

В GitHub Actions Secrets:
- `CLOUDFLARE_ACCOUNT_ID`
- `CLOUDFLARE_API_TOKEN`

В приватных переменных запуска:
- `ZEN_IMAGE_PROVIDER=cloudflare`
- `ZEN_CLOUDFLARE_FREE_PLAN_CONFIRMED=true` **только после проверки Workers Free**
- `ZEN_IMAGE_ALLOW_PAID=false`
- `ZEN_GENERATOR_RIGHTS` — реальный документированный правовой статус модели и изображений, подтверждённый владельцем.

Текущий `editorial_daily.py` передаёт окружение дочернему редакционному процессу. Однако существующие workflow ещё нужно проверить и явно передать им токены из GitHub Secrets через `env`. Секреты GitHub **не попадают в процессы автоматически**.

## Испытания, которые ещё требуются

1. Проверить GitHub Actions с явно переданными секретами на приватном runner, не публикуя черновики.
2. Получить реальный ответ Workers AI и убедиться, что он содержит декодируемое изображение.
3. Прогнать минимум семь сцен рассказа, выбрать обложку и проверить лицензию.
4. Посмотреть учёт Neurons в Cloudflare и проверить отказ при исчерпании бесплатной квоты.
5. Не включать Modal: пользовательский скриншот показывал workspace usage limit $1, но не подтверждал отдельный бесплатный баланс и нулевой предел оплаты.
6. После испытаний при желании объединить изменения через ревью основного PR №47.

Обнаружение отсутствующих ключей и недоступности API останавливает генерацию; никакой платной резервной площадки нет.
